# HTMX Projects

A collection of practical projects built with HTMX. Each project is kept in its own folder with its source code, configuration, and instructions for running it.

## Repository structure

```text
htmx_projects/
├── projects/
│   └── <project-name>/
│       ├── src/ or app files
│       ├── package.json or dependency files
│       └── README.md
└── README.md
```

Projects may use different server-side languages and frameworks. Check each project's README for its prerequisites, environment variables, and commands.

## Getting started

1. Choose a project under `projects/`.
2. Follow that project's README to install dependencies and configure the app.
3. Start the server using the instructions provided with the project.

## Projects

Projects will be listed here as they are added.

## Contributing

Keep each project self-contained, document its setup and configuration, and never commit private credentials or local `.env` files. Use `.env.example` files to describe required environment variables when needed.
